# Markdown to Website Converter

A small shell-based Markdown to HTML converter using [Pandoc](https://pandoc.org/) and XSLT.

The goal is to turn a directory of Markdown files into a website while preserving the directory structure.

## Requirements

* [Pandoc](https://pandoc.org/)
* Python
* POSIX-compatible shell environment

## Usage

The converter takes a Markdown file and an output HTML file:

```sh
./convert.sh input.md output.html
```

For example:

```sh
./convert.sh ./www/index.md ./public/index.html
```

### Converting an entire directory

The following example finds all Markdown files in `./www`, converts them to HTML, and preserves their directory structure under `$WEB_ROOT`:

```sh
# Find all markdown files and loop over each file's relative path
find ./www -name "*.md" | while read -r md_file; do
    # Make sure Markdown files land in the right place
    base=$(basename "$md_file" .md)
    rel=$(dirname "$md_file" | sed "s|^\./www[/]*||")

    if [ -n "$rel" ]; then
        dest="$WEB_ROOT/$rel/${base}.html"
        mkdir -p "$WEB_ROOT/$rel"
    else
        dest="$WEB_ROOT/${base}.html"
    fi

    echo "converting $md_file to $dest"
    ./markdown-to-website/convert.sh "$md_file" "$dest"
done
```

This turns a structure like:

```text
www/
├── index.md
├── about.md
└── projects/
    └── doom-truck.md
```

into:

```text
$WEB_ROOT/
├── index.html
├── about.html
└── projects/
    └── doom-truck.html
```

## Styling

Markdown to Website uses XSLT to transform the HTML output generated by Pandoc.

The transformation is defined in [`markdown.xslt`](markdown.xslt).

This makes the presentation layer independent from the Markdown itself. Modify the XSLT stylesheet to change the generated HTML without changing your Markdown files.

## How It Works

The conversion pipeline is intentionally simple:

```text
Markdown
   │
   ▼
 Pandoc
   │
   ▼
 HTML
   │
   ▼
 markdown.xslt
   │
   ▼
 Website
```

Pandoc handles Markdown parsing and produces the initial HTML representation. The XSLT stylesheet then transforms that output into the final HTML used by the website.
